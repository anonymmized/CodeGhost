
Server (Admin Alert Panel)

Лёгкий Flask-сервер в Docker, который принимает алерты от демона и даёт админу их просматривать и одобрять.

Запуск:

bash
cd server/
docker compose up --build
Эндпоинты:

POST /alert — демон отправляет сюда алерт когда файл изменился/создался/удалился.

GET /alerts — список всех необработанных алертов. Админ смотрит что произошло.

POST /approve — админ одобряет изменение файла. Тело запроса: {"file_path": "/path/to/file"}. После этого файл попадает в очередь на апрув.

GET /approvals — демон раз в 30 секунд забирает очередь одобренных файлов и обновляет baseline. После отдачи очередь чистится.

Флоу:

файл изменился
  → демон POST /alert
  → админ GET /alerts, видит изменение
  → админ POST /approve
  → демон GET /approvals (через 30 сек)
  → baseline обновлён, алерт закрыт
Запуск демона с сервером:

bash
./codeghost --config=config/config.json --server-url=http://127.0.0.1:5000
